# Fear

Fear is a text-based adventure game. The story starts with three characters: Bear, his mother and his brother, who are being chased by human hunters. Everyone gets separated, so now Bear tries to find them and stay alive with the hunters following his pawprints.

## Installation

Python 3.14 is required to play this game. [Python 3.14] (https://www.python.org/downloads/) to install Python.

##Run the program

```python
python fear.py
```
